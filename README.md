# Carbon-Aware Scheduling of AI Training Jobs
*Operations Research course project · Linear Programming + Integer Programming · Gurobi*

**Question:** A company must train 10 machine-learning models in the next 48 hours using GPU
data centres in Germany, Great Britain, France and California. Electricity in each region is
cleaner or dirtier depending on the hour (wind, sun, coal, nuclear). **In which region and which hour
should each job run so that total CO₂ is as low as possible**, while meeting deadlines,
GPU capacity limits and data-residency (privacy) rules?

## Quick start (macOS / Linux / Windows)

```bash
# 1. (optional) new environment
conda create -n orproj python=3.11 -y && conda activate orproj

# 2. install packages
pip install -r requirements.txt

# 3. make sure your Gurobi licence is active (academic licence: run grbgetkey once)

# 4. reproduce all numbers in the report (prints tables, writes results/*.csv)
python run_experiments.py

# 5. launch the dashboard (opens in your browser at http://localhost:8501)
streamlit run app.py
```

The data is already processed and included, so no internet connection is needed.

## Files

| File | What it does |
|---|---|
| `model.py` | **The OR model**: sets, parameters, variables, objective, constraints (Gurobi). 4 strategies. |
| `run_experiments.py` | Runs base case, scenarios, infeasibility demo, and all 51 weeks of 2020 → `results/` |
| `app.py` | Streamlit dashboard (6 tabs: data, schedule, comparison, shadow prices, sensitivity, formulation) |
| `prepare_data.py` | How the raw public data was converted to the hourly CSV (only needed to rebuild it) |
| `data/carbon_intensity_2020_hourly.csv` | Real hourly grid carbon intensity, 4 regions, full year 2020 (UTC) |
| `data/jobs.csv` | The 10 training jobs (assumed workload, editable in the dashboard) |
| `REPORT.md` | Submission write-up: problem, data, assumptions, formulation, approach, results, conclusions |
| `VIVA_GUIDE.md` | Likely viva questions with answers, and who explains what |
| `results/` | CSV outputs from `run_experiments.py` |
